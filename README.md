# EcoTravel — Responsive Landing Page

A complete Week 1 responsive landing-page project built with **semantic HTML5, modern CSS, and vanilla JavaScript**.

## Project concept

**EcoTravel** is a fictional sustainable-travel platform. The landing page promotes responsible destinations, eco-friendly stays, local experiences, and lower-impact travel.

### Main sections

- Responsive header and navigation
- Hero section with calls to action
- Traveler proof / rating cards
- Sustainable-travel feature highlights
- Featured destination cards
- Sustainable experience section
- Impact statistics
- Final call-to-action
- Responsive footer

## Files

```text
EcoTravel/

```

## How to run

1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. No build tools, npm, or server are required.

For the best development experience, you can also open the folder in VS Code and use a local server such as Live Server.

## Technologies used

- HTML5 semantic elements
- CSS3
- CSS Flexbox
- CSS Grid
- CSS media queries
- Vanilla JavaScript
- Google Fonts
- Responsive image backgrounds from Unsplash

## Responsive behavior

The layout is designed for:

- Desktop screens
- Tablets
- Mobile phones

At smaller widths, the desktop navigation changes into a hamburger menu. Destination cards, features, statistics, and the experience section also adapt to smaller screens.

## JavaScript functionality

`script.js` provides:

- Mobile navigation open/close
- Accessible `aria-expanded` state
- Escape-key menu closing
- Automatic copyright year
- Active navigation highlighting using `IntersectionObserver`

## Design choices

The design uses an earthy green palette, warm cream backgrounds, rounded cards, large editorial typography, and nature photography to communicate sustainable travel.

The page intentionally uses a simple component-like structure so that the code is easy to understand and modify for a Week 1 frontend assignment.

## Accessibility considerations

- Semantic HTML5 sections
- Descriptive navigation labels
- `aria-label` and `aria-expanded` for the mobile menu
- Keyboard Escape support
- Visible focus-friendly interactive controls
- Descriptive image `role`/labels for decorative background-image content

## Browser testing checklist

Test the page at approximately:

- 1440 × 900 — desktop
- 1024 × 768 — tablet/small desktop
- 768 × 1024 — tablet
- 390 × 844 — mobile
- 360 × 800 — small mobile

Also test:

- Opening/closing the mobile menu
- Clicking navigation links
- Keyboard Escape on the open menu
- Smooth scrolling
- Buttons and footer links
- Landscape mobile orientation

## Customization

To personalize the project:

- Change the text in `index.html`
- Update colors in the `:root` section of `style.css`
- Replace the Unsplash image URLs with your own images
- Add more destination cards
- Connect the CTA to a real booking/contact form
