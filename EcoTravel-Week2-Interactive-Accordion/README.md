# EcoTravel - Week 2 Interactive UI Component

## Project Title
EcoTravel Interactive FAQ Accordion

## Author
DURGADEVI.S

## Objective
Develop an interactive, responsive and accessible front-end component using HTML5, CSS3 and Vanilla JavaScript.

## Project Structure
- `index.html` - semantic page structure and FAQ markup
- `style.css` - responsive styling, states and animations
- `script.js` - DOM manipulation, event handling, accordion logic and error handling
- `README.md` - documentation and testing instructions

## Features
- Interactive FAQ accordion
- One FAQ open at a time
- Smooth CSS animation
- Semantic HTML
- ARIA `aria-expanded` and `aria-controls`
- Keyboard-friendly native buttons
- Visible focus states
- Responsive desktop/tablet/mobile layout
- Reduced-motion support
- JavaScript error handling
- Dynamic copyright year
- No external frameworks

## How to Run
Open `index.html` in a modern web browser. No installation is required.

## Testing
1. Click a question and verify that its answer opens.
2. Click the same question again and verify that it closes.
3. Open another question and verify that the previous one closes.
4. Use Tab to navigate between FAQ buttons.
5. Use Enter or Space to activate a focused button.
6. Test desktop and mobile screen sizes.
7. Check the browser console for JavaScript errors.

## Technologies
HTML5, CSS3 and Vanilla JavaScript.

## Accessibility
The FAQ uses native buttons, ARIA relationships, semantic headings and visible focus indicators. Native buttons support keyboard activation with Enter and Space.

## Learning Outcomes
This project demonstrates DOM manipulation, event handling, responsive design, CSS transitions, accessibility practices, reusable JavaScript functions and error handling.
